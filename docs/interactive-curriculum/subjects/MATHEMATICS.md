# SkillStorm Subject Blueprint — Matematika

> **Status:** `VISION / APPROVED`  
> **Owner:** Product + Pedagogy + Mathematics Review  
> **Last review:** 2026-08-08  
> **Scope:** Matematika na 1. i 2. stupni ZŠ; konkrétní pořadí témat určuje ŠVP školy.  
> **Purpose:** production-spec `Math Manipulative Lab` — přechod od konkrétní situace přes model a reprezentaci k symbolickému řešení.

---

## 1. Subject promise

**SkillStorm má matematiku učit jako práci s množstvím, vztahem, prostorem, daty a modelem — ne jako nekonečný worksheet se zelenou fajfkou.**

Základní smyčka:

```text
REAL / VISUAL PROBLEM
  ↓
ESTIMATE / PREDICT
  ↓
MANIPULATE REPRESENTATION
  ↓
NOTICE PATTERN / RELATIONSHIP
  ↓
FORMALIZE
  ↓
SOLVE NEW CASE
  ↓
EXPLAIN / CHECK REASONABLENESS
```

---

## 2. Kurikulární pozice

Matematika je samostatný obor oblasti `Matematika a její aplikace`. Revidovaný RVP ji strukturuje kolem čísla a početních operací, měření a výpočtů, geometrie, statistiky a pravděpodobnosti a algebry. SkillStorm nepředstírá pevnou státní ročníkovou osnovu; produkční obsah se mapuje na OVU/aspekty a ŠVP školy.

Oficiální reference: `https://prohlednout.rvp.cz/zakladni-vzdelavani/vzdelavaci-oblasti/mat`.

---

## 3. Pedagogický model

Matematická zkušenost má podporovat přechod:

```text
CONCRETE / CONTEXT
→ VISUAL MODEL
→ MULTIPLE REPRESENTATIONS
→ SYMBOLIC FORM
→ GENERALIZATION
```

Digitální prostředí je hodnotné hlavně tehdy, když umožní dynamicky propojit reprezentace, rychle měnit podmínky nebo zobrazit strukturu problému.

---

## 4. Delivery modes

### `BOARD_ONLY`
- společné manipulativy;
- odhad/predikce;
- geometrie;
- reprezentace graf/tabulka/rovnice;
- diskuse strategií.

### `SHARED_DEVICES`
- skupiny řeší různé strategie;
- porovnání více řešení;
- data/probability experiments.

### `DEVICES`
- individualizované problem-solving;
- adaptivní scaffolding;
- konstrukční geometrie;
- data investigation.

### `HYBRID`
Board drží společný problém, zařízení slouží jako laboratoř variant.

---

## 5. Lesson archetypes

1. **Manipulate → formalize**
2. **Estimate → measure/calculate**
3. **Represent the same thing three ways**
4. **Find the invariant**
5. **Build a counterexample**
6. **Data investigation**
7. **Probability experiment**
8. **Geometry construction**
9. **Optimization / trade-off**
10. **Error analysis** — najdi, kde a proč se řešení pokazilo.
11. **Model a real situation**
12. **Explain two different strategies**

---

## 6. Recommended progression

### 1.–2. ročník
- množství, číslo, číselná osa;
- rozklad čísla;
- základní operace jako manipulace;
- tvary, orientace, měření v konkrétních situacích;
- peníze a jednoduché reálné problémy.

### 3.–5. ročník
- větší čísla a operace;
- násobení/dělení jako vztah;
- zlomky přes model;
- obvod/obsah/měřítko v konkrétních úlohách;
- data, grafy, odhad;
- více strategií řešení.

### 6.–7. ročník
- záporná čísla;
- poměr/procenta;
- geometrické vztahy;
- algebra jako zobecnění;
- práce s daty a pravděpodobností;
- reálné rozpočty/měřítko.

### 8.–9. ročník
- funkční vztahy;
- rovnice/modelování;
- pokročilejší geometrie;
- statistická interpretace;
- pravděpodobnost;
- optimalizace a modely reálných situací.

Recommended progression se přizpůsobuje ŠVP.

## 7. Experience catalog

### MATH-01 — Number Landscape
Čísla jsou pozice na ose, ne izolované kartičky. Žák odhaduje, posouvá a vysvětluje vzdálenost.

### MATH-02 — Build the Number
Rozklad čísla pomocí bloků/skupin. Stejný engine později podporuje place value.

### MATH-03 — Classroom Shop
Rozpočet, ceny, vracení, více možných nákupů. Finance bez skutečných osobních dat.

### MATH-04 — Multiplication Array Lab
Násobení jako struktura pole/skupin; přechod k symbolickému zápisu.

### MATH-05 — Fraction Kitchen
Změna počtu porcí propojuje konkrétní model, zlomek a výpočet.

### MATH-06 — Fraction Comparison
Žák vytváří vizuální důkaz, ne pouze volí větší číslo.

### MATH-07 — Scale Mission
Plán místnosti/mapa/objekt a převod mezi reprezentací a skutečností.

### MATH-08 — Geometry Construction Lab
Body, přímky, úhly, tvary, constraints. Hodnotí se konstrukční reasoning.

### MATH-09 — Playground Designer
Návrh plochy s omezením rozměrů, obvodu/obsahu a průchodnosti.

### MATH-10 — Algebra Tiles
Manipulace s členy vede k rovnici a ekvivalentním úpravám.

### MATH-11 — Function Machine
Vstup → pravidlo → výstup; tabulka, graf a rovnice se synchronizují.

### MATH-12 — Break-even Challenge
Dvě nabídky/náklady. Žák hledá bod průsečíku a vysvětluje jeho význam.

### MATH-13 — Data Room
Dataset má odlehlé hodnoty, chyby a více způsobů vizualizace. Žák řeší, co data podporují.

### MATH-14 — Probability Lab
Opakovaný náhodný experiment propojuje teoretický model a empirickou četnost.

### MATH-15 — Misleading Graph Detective
Žák hledá, jak volba osy/škály ovlivňuje interpretaci.

### MATH-16 — Error Clinic
Dostane realistické chybné řešení a musí najít první chybný krok a vysvětlit ho.

### MATH-17 — Optimize the Plan
Rozpočet/prostor/čas mají constraints. Více řešení může být správných.

### MATH-18 — Pattern Generalizer
Žák manipuluje s posloupností/vzorem a vytváří obecné pravidlo.

## 14. Mathematical integrity

- žádný „trik“ prezentovaný jako obecné pravidlo bez podmínek;
- grafy mají korektní osy/jednotky;
- randomizace je reprodukovatelná;
- více správných řešení není vynuceno do jednoho answer key;
- aproximace je označena;
- teacher může zobrazit assumptions;
- AI-generated solution/explanation musí projít review u kurátorovaného globálního obsahu.

## 15. Hero lesson A — Function Machine

**Range:** typicky 8.–9. ročník dle ŠVP  
**Mode:** `HYBRID`  
**Duration:** 45 min

### Hook
Dvě služby mají jiné fixní a proměnné náklady.

> Kdy je která výhodnější?

### Prediction
Žáci odhadnou průsečík bez rovnice.

### Exploration
Zařízení/tablet mění vstupní hodnotu; board synchronizuje tabulku a graf.

### Formalization
Rovnice se odemkne až po práci s daty a grafem.

### Challenge
Nová cenová struktura. Žáci vysvětlují význam průsečíku.

### Reflection
Co znamená bod mimo reálnou doménu problému?

Evidence: estimate → table/graph reasoning → symbolic solution → contextual explanation.

---

## 16. Hero lesson B — Navrhni školní odpočinkovou zónu

**Range:** 4.–6. ročník podle ŠVP  
**Mode:** `BOARD_ONLY` / `SHARED_DEVICES`  
**Duration:** 45–60 min

Třída dostane půdorys a constraints:

- maximální plocha;
- průchod;
- rozpočet;
- několik velikostí prvků.

Žáci navrhují variantu a musí doložit rozměry, obvod/obsah a rozpočet.

Více řešení je legitimních.

Evidence: návrh + calculation + explanation + revision after constraint conflict.

## 17. MVP vertical slice

**Function Machine**

Prokazuje:

- synchronized representations;
- manipulaci parametry;
- prediction before reveal;
- transfer challenge;
- multiple representations;
- teacher orchestration;
- accessible table alternative.

Pro 1. stupeň paralelní malý slice `Number Landscape` reuse stejný kernel, ale není nutný pro první engine proof.

---

## 18. Non-goals

- nekonečný generátor příkladů jako hlavní produkt;
- speed leaderboard;
- veřejné porovnávání žáků;
- AI, která žákovi rovnou řešení vypíše;
- nahrazení manipulativů na 1. stupni tam, kde fyzický objekt funguje lépe;
- CAS systém;
- univerzální dynamická geometrie se všemi funkcemi v MVP;
- známkování podle počtu kliků.

---

## 19. Production acceptance criteria

```text
[ ] math reviewer schválil korektnost
[ ] curriculum mapping reviewed
[ ] multiple-solution tasks support valid alternatives
[ ] graph/table/equation synchronization tested
[ ] seeded randomness reproducible
[ ] no hidden precision traps
[ ] accessibility alternatives exist
[ ] no public performance ranking
[ ] teacher can pause/compare strategies
[ ] content values can change without renderer rewrite
[ ] evidence measures reasoning, not only final answer
[ ] fallback/printable strategy exists where useful
```
